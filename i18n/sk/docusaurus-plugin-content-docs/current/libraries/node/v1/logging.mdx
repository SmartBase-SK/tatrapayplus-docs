# Logging

# TBPlusLogger

`TBPlusLogger` je exportovaný z `@tatrabanka/tatrapayplus-node` (od verzie 1.0.2) a slúži ako jednoduchý a prispôsobiteľný HTTP logger pre `TBPlusSDK`.
Pomáha vám ladiť volania API zaznamenávaním odchádzajúcich požiadaviek a prichádzajúcich odpovedí a zároveň bezpečne maskuje citlivé údaje.

---

## Funkcie

- Zaznamenáva metadáta **žiadostí a odpovedí**
- Vstavané **maskovanie polí**
- Rozšíriteľné pomocou `writeLine()` na prispôsobenie výstupu (konzola, súbor atď.)

## Maskované polia

Logger maskuje citlivé hodnoty pred ich výstupom:

- **Headers**: `Authorization`
- **Body fields (request and response)**: `client_id`, `client_secret`, `access_token`

Príklad maskovaného výstupu: `client_secret=abcde*************uvxyz`

Maskovanie môžete vypnúť odovzdaním `false` konštruktoru:

```javascript
const logger = new TBPlusLogger(false);
```

## Príklad použitia

### Krok 1: Vytvorenie podtriedy Loggeru

```javascript
import { TBPlusLogger } from "@tatrabanka/tatrapayplus-node";

class ConsoleLogger extends TBPlusLogger {
  protected writeLine(line: string): void {
    console.log("[ConsoleLogger]", line);
  }
}
```

### Krok 2: Vloženie loggeru do klienta

```javascript
import { TBPlusSDK, TBPlusLogger } from "@tatrabanka/tatrapayplus-node";

const logger = new ConsoleLogger();

const sdk = new TBPlusSDK(API_KEY, API_SECRET, {}, logger);

const { data, error } = await sdk.createPayment(
  paymentBody,
  REDIRECT_URI,
  "192.0.2.123"
);
```
